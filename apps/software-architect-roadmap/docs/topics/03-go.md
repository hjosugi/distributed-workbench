# 03. Go / Golang

[All 53 topics](../ROADMAP.md) · 1. Programming languages · **Executable HTTP service**

## Meaning and purpose

Go provides static types, garbage collection, and lightweight goroutines. Its standard HTTP package is enough for a small service. Clear interfaces and explicit errors make dependencies easy to inspect.

## How the example works

A typed Product struct controls JSON names. A handler chooses the route, writes the status, and uses json.Encoder. Server read and write timeouts bound slow clients. GOWORK=off isolates the example from the parent repository workspace. The module declares Go 1.24 as a minimum, not the newest Go release.

Implementation: [examples/catalog/go/main.go](../../examples/catalog/go/main.go), [examples/catalog/go/main_test.go](../../examples/catalog/go/main_test.go).

## Tradeoffs and failure cases

A goroutine does not remove the need for cancellation, backpressure, or race protection. Concurrent access to a mutable map still needs coordination. This fixture is immutable and does not require locks.

## Practice and interview discussion

Add a cancellation-aware downstream request using the incoming request context. Explain when a buffered channel helps and when it merely hides overload. Interview phrase: I pass cancellation through the request path.

Explain the requirement, the mechanism, and the failure boundary before naming a product. For an integrated interview answer, use [the order-system script](../SYSTEM_DESIGN.md).
